# PARADIGMA DE INGENIERÍA DE SOFTWARE DEL PROYECTO

**Asignatura:** Ingeniería de Software | **Carrera:** Ingeniería en Datos e Inteligencia Artificial

**Proyecto:** PROYECTO FINAL INGENIERÍA DE SOFTWARE

**Integrantes:** Isela Carranco Martínez, Carla Guadalupe Ruiz Vallejo, Manuel Arreguín Tamayo

## 1. MÉTODOS (Técnicas Sistemáticas de Desarrollo)

- **Modelo de Proceso:** Desarrollo Incremental, mediante la implementación progresiva
  de las funcionalidades del sistema. El proyecto se dividirá en incrementos que
  permitan desarrollar, integrar y validar las diferentes partes del sistema.
- **Técnicas de Análisis y Especificación:** Historias de  Usuario para identificar
  las necesidades de los usuarios y definir las funcionalidades que deberá cumplir
  el sistema. Se utilizará el modelado de software para representar la estructura
  y comportamiento del sistema antes de su implementación.
- **Técnicas de Validación:** Pruebas funcionales y pruebas unitarias para verificar
  el correcto funcionamiento del sistema, complementadas con revisiones e
  inspecciones de pares mediante Pull Requests.

## 2. HERRAMIENTAS (Soporte Automatizado CASE y Entorno de Desarrollo)

- **Entorno Integrado (IDE):** Visual Studio Code para el desarrollo y edición
  del código fuente.
- **Control de Versiones y SCM:** Git CLI local y GitHub Remote Repository.
- **Analizador Estático de Código (Linter):** Flake8.
- **Gestión de Tareas:** Tablero Kanban en GitHub Projects.

## 3. PROCEDIMIENTOS (Estructura y Normativa Organizacional)

- **Formato de Commits:** feat:, fix:, docs:, style:, refactor:.
- **Estrategia de Ramas (Branching):** Prohibido hacer push directo a main. Todo cambio se realiza en feature/* y requiere Pull Request.
- **Política de Code Review:** Todo Pull Request requiere aprobación escrita de al menos 1 integrante antes del Merge.
